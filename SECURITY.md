# Security policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Report privately through either channel:

- **GitHub private vulnerability reporting** (preferred): open the repository's **Security** tab and choose **Report a vulnerability**. This creates a private advisory visible only to maintainers.
- **Email**: `info@10xmedia.de`.

Include the affected package and version, a description of the issue, reproduction steps, and the potential impact. We will acknowledge the report, work with you on a fix, and credit you in the resulting advisory unless you ask to remain anonymous.

## Supported versions

The project is in beta; `@10x-media/*` packages publish as `0.x` releases under the `beta` dist-tag. Security fixes land on the latest published version of each package. Older betas are not maintained, so upgrade to the latest release to receive fixes.
