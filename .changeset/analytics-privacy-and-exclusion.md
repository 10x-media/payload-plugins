"@10x-media/analytics": minor

Staff can take themselves out of the numbers with a link, and the docs say what a stored event holds.

**Additive:** any page opened with `?analytics_exclude=1` takes that browser out of capture, and `=0` puts it back (`true` and `false` work too). The tracker reads the parameter on boot and leaves the URL alone. While the flag is set nothing is delivered to any sink, nothing is queued for a pending consent decision, and no vendor script is injected even after consent is granted; clearing resumes from that point and replays nothing that was skipped. The flag lives in `localStorage` under `analytics:exclude`, so it is per browser and per site, and a browser with storage blocked is excluded for the page the link was opened on and no further, without throwing.

**Additive:** `exclusionParam` on `createTracker`/`initTracker` options, beside `persistConsent`. A string renames the parameter, `false` ignores it while still honouring a flag an earlier visit set. Default `analytics_exclude`.

**Additive:** `tracker.exclude(next)` and the read-only `tracker.excluded` on the `Tracker` interface, `setExcluded` and `excluded` on `useAnalytics()`, and `EXCLUSION_STORAGE_KEY`, `DEFAULT_EXCLUSION_PARAM`, `readExclusion`, `writeExclusion`, `readExclusionParam` and `subscribeExclusion` from `@10x-media/analytics/tracker`, for a host rendering its own switch. `AnalyticsApi` gains the `excluded` flag and is now `AnalyticsCommands` (the imperative half, also exported from `@10x-media/analytics/react`) plus that flag; nothing was removed from it, and the React context itself is not part of the package's export surface.

**Additive:** the vendor sinks expose their own opt-out through the optional `Sink.exclude`, with `PLAUSIBLE_IGNORE_KEY`, `UMAMI_DISABLED_KEY`, `GA4_DISABLE_PREFIX` and `Ga4SinkArgs` exported alongside them.

**Behavioral:** a visitor who arrives with the parameter is excluded from then on in that browser, and the exclusion is mirrored into each vendor's own switch for the slots the config has: `plausible_ignore`, `umami.disabled`, PostHog's `opt_out_capturing()` and GA4's `ga-disable-<measurementId>`. A snippet the server rendered for a slot that does not require consent runs before the tracker boots, so that vendor's own page view for the page the link was opened on may already have been sent; Plausible, Umami and PostHog persist their switch and are silent from the next load. GA4's is a window property that does not persist and counts only ahead of the first `gtag()` call, so the rendered GA4 snippet reads `analytics:exclude` itself and sets the switch before its own `gtag('config', ...)`: the page the link is opened on may still be measured, and from the next page load on nothing is. A gated slot, which is GA4's default, never loads while the browser is excluded. A vendor key the tracker did not set is cleared only by an explicit `=0` or `exclude(false)`, so one a staff member set by hand survives an ordinary visit; an explicit clear does clear it, which is the cost of off meaning off.

**Breaking (types only):** the exported `Tracker` type gains two required members, `excluded` and `exclude`. Code that implements `Tracker` itself, such as a test double or a wrapper, has to add them. Callers are unaffected.

**Behavioral:** the tracker's built entry grows by about 5.8 KB (34,837 bytes transitive, from 29,042). It stays dependency-free.

**Additive:** a Privacy page in the docs states, column by column, what a stored native event holds and where each value comes from, that no cookie is set and which `localStorage` keys exist, how the daily-salted visitor hash works and why two days cannot be joined once its salt is swept, that the client address is used for the hash and geo and stored nowhere, that the raw query string is read for the campaign keys and the ad click ids and then discarded, what a `path` or a prop the site authors can therefore carry, and what an access or erasure request can and cannot find. It states facts about the code and makes no legal claim. Capture documents the exclusion link beside it, including what a link carrying the parameter costs when anyone sends one to a real visitor.
