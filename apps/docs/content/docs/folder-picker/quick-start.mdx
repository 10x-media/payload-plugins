## Requirements

- A folder collection: any collection with `folders: true`.
- At least one collection filed into it, through `createFolderField({ relationTo: '<folder slug>' })`.

Both are Payload features, not this plugin's. A collection that is filed into no folder collection keeps the stock drawer.

## Install

```bash
pnpm add @10x-media/folder-picker@alpha
```

## Configure

```ts title="payload.config.ts"
import { buildConfig, createFolderField } from 'payload'
import { folderPicker } from '@10x-media/folder-picker'

export default buildConfig({
  collections: [
    {
      slug: 'folders',
      admin: { useAsTitle: 'name' },
      folders: { collectionSpecific: true },
      fields: [{ name: 'name', type: 'text', required: true }],
    },
    { slug: 'media', upload: true, fields: [createFolderField({ relationTo: 'folders' })] },
    {
      slug: 'posts',
      fields: [{ name: 'cover', type: 'upload', relationTo: 'media' }],
    },
  ],
  plugins: [folderPicker({})],
})
```

`collectionSpecific` is optional. With it, each folder lists the collections it may hold, and the drawer only shows the folders that accept the collection it picks from.

## Regenerate the import map

```bash
payload generate:importmap
```

Development regenerates it on boot; a production build uses the committed file. Skip this and the drawer silently falls back to the default list, with `getFromImportMap: PayloadComponent not found` in the server log. A TanStack Start app keeps an import map of its own; regenerate that one too.

## Try it

1. Open **Folders** and create a folder.
2. Upload a file and set its folder.
3. Open a Post and press **Choose from existing** on the `cover` field.

The drawer now has **All Media** and **By Folder** tabs. Click a folder to enter it, and the trail to go back up. Click a file's name to pick it; on a `hasMany` field, tick several and press **Confirm**.

## Turning it off

Per environment:

```ts
folderPicker({ disabled: process.env.NODE_ENV === 'test' })
```

Per collection, drop its folder field. There is no per-field switch; see [Limits](/folder-picker/limits).
