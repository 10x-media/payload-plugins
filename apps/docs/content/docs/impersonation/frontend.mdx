The admin bar is Payload-only. On the website, drop in the shipped banner or copy the two calls it makes.

## Shipped banner

Server component. Renders nothing when this request is not the impersonated session. Minimal default styles, no admin CSS.

```tsx title="app/(frontend)/layout.tsx"
import { ImpersonationFrontendBanner } from '@10x-media/impersonation/rsc'
import { headers } from 'next/headers'
import { getPayload } from 'payload'
import config from '@payload-config'

export default async function Layout({ children }) {
  const payload = await getPayload({ config })
  return (
    <html>
      <body>
        <ImpersonationFrontendBanner payload={payload} headers={await headers()} />
        {children}
      </body>
    </html>
  )
}
```

Pass `user` if you already called `payload.auth`, so the banner does not authenticate again. `className` and `labels` (`actingAs` with `{{name}}`, `exit`) are the styling and copy hooks. The default look has zero specificity, so your own class overrides it without `!important`. Pass `unstyled` to drop it and style the `impersonation-frontend-banner`, `__text`, and `__exit` classes yourself. The name follows `ui.userLabel` (`useAsTitle` by default); pass `userLabel="email"` or `"title"` to override it for the banner. Exit reloads only when the request succeeds.

## TanStack Start

TanStack Start renders a route's component on the client, so the server-component banner has no place there. Split it the same way the banner does internally: `getFrontendBanner` on the server, `ImpersonationFrontendBannerView` in the component. The view renders the same markup, classes and default look.

```tsx title="src/app/index.tsx"
import { ImpersonationFrontendBannerView } from '@10x-media/impersonation/client'
import { createFileRoute } from '@tanstack/react-router'
import { createServerFn } from '@tanstack/react-start'
import { getRequest } from '@tanstack/react-start/server'

const loadBanner = createServerFn({ method: 'GET' }).handler(async () => {
  const [{ getPayload }, { getFrontendBanner }, { default: config }] = await Promise.all([
    import('payload'),
    import('@10x-media/impersonation'),
    import('@payload-config'),
  ])
  return getFrontendBanner({
    headers: new Headers(getRequest().headers),
    payload: await getPayload({ config }),
  })
})

export const Route = createFileRoute('/')({
  component: Page,
  loader: () => loadBanner(),
})

function Page() {
  return <ImpersonationFrontendBannerView banner={Route.useLoaderData()} />
}
```

`getFrontendBanner` takes the banner's `labels`, `user` and `userLabel` and returns `null` when the request is not the impersonated session; the view takes `className` and `unstyled`. Load the server modules inside the handler, as above, so they stay out of the client bundle. In parallel mode the website request must reach Payload with its frontend scope, which on TanStack Start is `@10x-media/dual-session`'s request middleware.

## Build your own

Status on the server, one POST to exit:

```tsx
import { getImpersonation } from '@10x-media/impersonation'

const status = await getImpersonation({ headers, payload, user })
if (!status.active || status.side !== 'target') return null

// Exit:
await fetch('/api/impersonation/exit', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json' },
  body: '{}',
})
```

`side: 'target'` is the impersonated session. `side: 'impersonator'` is the admin side of a parallel session (you are still yourself).
