Payload v3 plugins built and maintained by [10x Media](https://github.com/10x-media/payload-plugins). Every plugin is native to Payload: collections, jobs, access control, and admin components come from Payload itself, not a parallel runtime.

<Callout type="info">
All packages are in beta, published to npm under the `beta` dist-tag. Expect breaking changes until a stable release.
</Callout>

## Shared conventions

The plugins share one factory shape, one opt-in convention, and one translations pattern. Read them once in [Concepts](/concepts); every plugin's pages link there instead of repeating them.

## Requirements

All plugins target Payload `^3.82.0` and React 19, and require Node 22.18 or newer.
