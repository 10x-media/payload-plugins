title: Quick start
description: Install document-preview, enable it on an upload collection, and open your first preview.
---

## Install

```bash
pnpm add @10x-media/document-preview@alpha
```

The office renderers, the CSV parser and the Markdown renderer are regular dependencies, so there is nothing else to install. They only reach the browser when a file of their kind is opened.

## Configure

List the upload collections that get previews. `true` takes the defaults: the preview in the edit view's file panel, file-type icons for non-image thumbnails, and a readable file size in the list.

```ts title="payload.config.ts"
import { buildConfig } from 'payload'
import { documentPreview } from '@10x-media/document-preview'

export default buildConfig({
  collections: [
    {
      slug: 'media',
      upload: true,
      fields: [{ name: 'alt', type: 'text' }],
    },
  ],
  plugins: [
    documentPreview({
      collections: {
        media: {
          listView: true, // a Preview column in the list view, opening a drawer
        },
      },
    }),
  ],
})
```

A collection that does not exist, or is not an upload collection, is a config error at startup.

The plugin adds admin components, so regenerate the import map:

```bash
pnpm payload generate:importmap
```

The plugin adds no database fields: the list column is a UI field, so there is nothing to migrate.

## Open a preview

Open any document of the collection: the file panel beside the fields shows the file. With `listView`, press **Preview** in a row of the list to open it in a drawer. Both show the saved file; a replacement you have picked but not saved yet has no URL to preview.
