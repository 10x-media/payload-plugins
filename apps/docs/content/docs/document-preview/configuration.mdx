---
title: Configuration
description: Every document-preview option.
---

```ts
documentPreview({
  collections: {
    [uploadSlug]: true | {
      listView?: boolean                     // default false
      nativePreviews?: boolean               // default: the global nativePreviews
      fileIcons?: boolean                    // default: the global fileIcons
      filesizeCell?: boolean                 // default true
      viewers?: { [mimePattern: string]: string }
    },
  },
  viewers?: { [mimePattern: string]: string }
  nativePreviews?: boolean                   // default true
  fileIcons?: boolean | {                    // default true
    types?: { [mimePattern: string]: { label: string; color: string } | { svg: string } }
  }
  disabled?: boolean
  translations?: TranslationsOption
})
```

## Plugin

| Option | Default | |
|---|---|---|
| `collections` | required | The upload collections that get previews. `true` takes the defaults; an object customizes. A slug that does not exist, or is not an upload collection, is a config error. |
| `viewers` | `{}` | Viewer components for every enabled collection, by mime pattern. See [custom viewers](/document-preview/custom-viewers). |
| `nativePreviews` | `true` | The default for every collection's `nativePreviews`. |
| `fileIcons` | `true` | The default for every collection's `fileIcons`. An object turns icons on and adds your own `types`. See [file icons](/document-preview/file-icons). |
| `disabled` | `false` | Return the config untouched, for opting out per environment. |
| `translations` | `{}` | Per-locale overrides for the admin strings. See [i18n](/document-preview/i18n). |

## Per collection

| Option | Default | |
|---|---|---|
| `listView` | `false` | A **Preview** column in the list view, opening the file in a drawer. See [surfaces](/document-preview/surfaces). |
| `nativePreviews` | the global `nativePreviews` | Leave images, video, audio and PDF to Payload's own previews in the file panel. `false` uses the plugin's viewers for them too. |
| `fileIcons` | the global `fileIcons` | File-type icons for this collection's non-image thumbnails. |
| `filesizeCell` | `true` | Show `filesize` as `1.2 MB` in the list view. A `Cell` the collection sets on `filesize` itself is kept. |
| `viewers` | `{}` | Viewer components for this collection only, checked before the global `viewers`. |

Mime patterns are lowercase: an exact mime (`video/mp4`) or a type wildcard (`video/*`). A malformed pattern is a config error.

## Fields the plugin adds

| Field | When | |
|---|---|---|
| `documentPreviewColumn` | `listView` | UI field, last in the collection, carrying the list cell. Stores nothing. |
| `filesize` | `filesizeCell` | Only an admin `Cell`, merged into Payload's upload field. |
| `thumbnailURL` | `fileIcons` | Only an `afterRead` hook, merged into Payload's upload field. |

None of them adds a column to the database. A collection that already has a field named `documentPreviewColumn` is a config error.

The preview in the file panel is the collection's `upload.admin.components.filePreview`: a map from mime pattern to the plugin's `DocumentPreviewFilePreview`, covering the types the plugin previews (every type with `nativePreviews: false`). A `filePreview` the collection sets itself is kept; see [surfaces](/document-preview/surfaces#file-panel).
